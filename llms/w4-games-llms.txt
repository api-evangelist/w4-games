# W4 Games

> W4 Games commercializes the open-source Godot game engine — offering professional services, console ports, mobile/XR platform work, and premium support — and operates W4 Cloud (W4GD), a managed multiplayer backend-as-a-service for Godot. W4 Cloud covers player authentication, a Supabase/PostgREST database accessed through the W4 Relational Mapper (W4RM) ORM, realtime, storage, matchmaking and lobbies, WebRTC, analytics, and Agones-based dedicated game-server fleets. It is consumed through the w4gd Godot editor addon (a GDScript SDK) rather than a standalone public REST API. Backed by Lux Capital.

## Getting started
- [Getting started with W4 Cloud](https://docs.w4.gd/tutorials/getting_started/index.html): Hands-on tutorial to run an online multiplayer game round.
- [Installation](https://docs.w4.gd/getting_started/installation.html): Download w4gd.zip from releases and enable the addon (Godot 4.0+).
- [Player authentication](https://docs.w4.gd/getting_started/authentication.html): Project API key + Supabase JWT player auth.
- [Database management](https://docs.w4.gd/getting_started/database/index.html): Using the W4 Relational Mapper (W4RM) ORM.
- [Matchmaker](https://docs.w4.gd/getting_started/matchmaker/index.html): Lobbies, automated matchmaking, WebRTC.
- [Dedicated servers](https://docs.w4.gd/getting_started/dedicated_servers/index.html): Uploading builds and Agones fleet setup.
